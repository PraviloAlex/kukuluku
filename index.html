Kukuluku — In-page Translator

Privacy Policy

Last updated: May 2026

Kukuluku does not collect, sell, or share your personal data. The extension is designed for quick in-page translation without user accounts, advertising, analytics, or third-party tracking.

Translation

When you select text on a webpage, it may be sent to the Google Translate service to produce a translation.

This request is made from your browser for the purpose of providing the translation. Kukuluku does not log, store, sell, or share the selected text.

AI Explanations — Optional

If you choose to use AI explanations, you provide your own API key from a third-party provider such as Anthropic, OpenAI, Google, or xAI.

When you request an explanation, the selected text may be sent to the provider's API using your own API key.

Kukuluku does not proxy, log, or store these AI explanation requests.

API Keys

API keys provided by the user are stored in Chrome extension storage and are used only to connect to the AI provider selected by the user.

Kukuluku does not send your API keys to the developer's server.

What Is Stored in Your Browser

Kukuluku may store extension preferences, including:

  • Your preferred translation language
  • Your chosen theme: dark or light
  • Your chosen mode: automatic translation or hotkey mode
  • Your UI language
  • Your optional API keys, if you choose to add them

You can remove this data at any time by uninstalling the extension via chrome://extensions, or by removing your API keys in the extension settings.

No Analytics. No Accounts. No Ads. No Tracking.

Kukuluku contains no analytics scripts, no user accounts, no advertising, and no third-party tracking of any kind.

Third-Party Services

Kukuluku may communicate with the following services on your behalf:

  • Google Translate service — https://policies.google.com/privacy
  • Anthropic API, if used — https://www.anthropic.com/privacy
  • OpenAI API, if used — https://openai.com/privacy
  • Google Gemini API, if used — https://policies.google.com/privacy
  • xAI API, if used — https://x.ai/privacy

These services are only contacted when you actively use the corresponding feature. Kukuluku does not share data between providers.
