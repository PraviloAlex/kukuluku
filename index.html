Kukuluku — Privacy Policy Last updated: May 2026 Kukuluku does not collect, store, or share your personal data. ——————————————————————————— TRANSLATION ——————————————————————————— When you select text on a webpage, it is sent to the Google Translate API to produce a translation. This request goes directly from your browser to Google's servers. Kukuluku does not see, log, or store this text. ——————————————————————————— AI EXPLANATIONS (OPTIONAL) ——————————————————————————— If you choose to use AI explanations, you provide your own API key from a third-party provider (Anthropic, OpenAI, Google, or xAI). When you request an explanation, the selected text is sent directly from your browser to that provider's API using your key. Kukuluku does not proxy, log, or store these requests. Your API key is stored locally in Chrome's built-in storage (chrome.storage.sync) and is never transmitted anywhere by Kukuluku. ——————————————————————————— WHAT IS STORED LOCALLY IN YOUR BROWSER ——————————————————————————— - Your preferred translation language - Your chosen theme (dark / light) - Your chosen mode (auto / hotkey) - Your UI language - Your optional API keys (per provider) All of this stays in your browser. You can remove it at any time by uninstalling the extension via chrome://extensions. ——————————————————————————— NO ANALYTICS. NO ACCOUNTS. NO ADS. NO TRACKING. ——————————————————————————— Kukuluku contains no analytics scripts, no user accounts, no advertising, and no third-party tracking of any kind. ——————————————————————————— THIRD-PARTY SERVICES ——————————————————————————— Kukuluku may communicate with the following services on your behalf: - Google Translate API https://policies.google.com/privacy - Anthropic API (if used) https://www.anthropic.com/privacy - OpenAI API (if used) https://openai.com/privacy - Google Gemini API (if used) https://policies.google.com/privacy - xAI API (if used) https://x.ai/privacy These services are only contacted when you actively use the corresponding feature. Kukuluku does not share data between providers. ——————————————————————————— CONTACT ——————————————————————————— Questions or concerns? Reach out via Telegram: https://t.me/BizCalc_bot
