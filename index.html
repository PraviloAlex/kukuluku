What data is processed

Kukuluku does not operate its own processing servers and does not require an account. During use, the following is sent directly to third-party providers:

  • Selected text — sent to Google Translate and, if enabled, to your chosen AI provider.
  • Target language — sent as part of translation requests.
  • Translation provider — Google Translate is used for core translations.
  • AI provider — optional explanations via Claude, GPT, Gemini, or Grok.

When translation or AI explanation is requested, selected text is processed under the third-party provider's own policy. Kukuluku does not control third-party retention or downstream processing.

02
02

API keys

API keys are stored locally on your device only using chrome.storage.local.

Keys are not sent to Kukuluku infrastructure.

03
03

Recent translation history

Kukuluku can store recent translations locally in your browser so you can review or copy them from the extension popup.

This history may include the selected text, the translated text, source language, target language, and timestamp.

Recent translation history is stored using chrome.storage.local. It is not sent to Kukuluku servers and can be cleared from the extension settings.

04
04

Local usage counters

Kukuluku stores local counters, for example translation count and active days, to decide when to show optional rating or support prompts.

These counters contain no personal identifiers and stay on your device.

05
05

No analytics, no ads, no sale

Kukuluku does not include analytics trackers or ad SDKs and does not sell user data.

Kukuluku uses user data only to provide and improve selected-text translation and optional AI explanations, and complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

06
06

Third-party services

Selected text may be sent to the following services depending on your settings:

  • Google Translate — core translation. Google Privacy
  • Anthropic Claude — optional AI explanations. Anthropic Privacy
  • OpenAI GPT — optional AI explanations. OpenAI Privacy
  • Google Gemini — optional AI explanations. Google Privacy
  • xAI Grok — optional AI explanations. xAI Privacy
07
07

How to delete your data

  • Remove Kukuluku from chrome://extensions — this clears extension local storage.
  • To remove only API keys: open Kukuluku → Advanced → AI explanations → clear key field → Save key.
  • To remove recent translation history: open Kukuluku → History → Clear.
